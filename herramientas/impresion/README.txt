IMPRESIÓN GUSANIZA — MEDIDAS CORREGIDAS

Medidas físicas exactas a 300 DPI:
- Base blanca: 21.59 × 27.90 cm.
- Cada imagen: 5.77 × 8.81 cm.
- Separación horizontal entre imágenes: 1 cm.
- Separación vertical entre filas: 2 cm.
- Distribución: 3 columnas × 2 filas, centradas en la base.

Las seis imágenes se adaptan a marcos del mismo tamaño. La imagen se ajusta al marco sin dejar franjas blancas internas; si la proporción original es distinta, puede deformarse ligeramente. La vista previa muestra guías que no aparecen en el JPG final.

SUBIR A VERCEL:
- Descomprime el ZIP.
- Importa la carpeta gusaniza_fix como proyecto en Vercel.
- No necesita Node.js, backend ni base de datos.
