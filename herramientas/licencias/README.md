# Lisencias Gusaniza V21

Editor PSD en navegador basado en ag-psd.

## Cambios V20
- Zoom de vista hasta 300%.
- El zoom solo cambia la visualización; no modifica la resolución real del PSD.
- La vista previa ahora está dentro de un área con desplazamiento horizontal y vertical cuando el zoom supera el tamaño disponible.
- El botón Fit vuelve a 100% y centra la plantilla en el área de visualización.
- En las capas de texto se agregó selector de grosor: Regular o Bold.
- Ambos modos usan Arial y conservan el color configurado para las plantillas (#404048).
- No se modificó el sistema de reemplazo de imágenes de V19.
- Guardar JPG sigue exportando a la resolución real del PSD.


## Mejoras V21 para móvil
- Diseño adaptable para iPhone y otros teléfonos, en vertical y horizontal.
- En pantallas pequeñas se muestran las capas y propiedades; no se ocultan los comandos de la derecha.
- Selector de archivos PSD compatible con el explorador de archivos de iOS cuando el archivo está disponible en Archivos.
- Se conservan el procesamiento PSD, la edición de capas, el zoom, el reemplazo de imágenes y la exportación JPG a resolución real.
