# Gusaniza PSD Editor V22

Sube TODO el contenido de esta carpeta a Vercel (incluida `plantillas/`). El archivo `index.html` y la carpeta `plantillas` deben estar en la misma raíz pública.

La biblioteca se abre automáticamente. El botón Biblioteca PSD permite volver a abrirla. Los 4 PSD se descargan desde rutas relativas del mismo sitio; después se procesan localmente en el navegador mediante el motor original de V21. El botón Abrir PSD local sigue disponible.

No se inspeccionó ni se procesó el contenido de los PSD durante la preparación; únicamente se copiaron sus bytes sin modificación.

Importante: abrir `index.html` directamente como file:// no permite cargar las plantillas por fetch; publicar en Vercel o usar un servidor HTTP local. Mantén la versión V21 como respaldo hasta probar las cuatro plantillas en iPhone y escritorio.
